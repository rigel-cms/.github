# Rigel CMS

The copy editor for Astro sites.

Edit website copy and Markdown posts, preview changes on prepared pages, and publish through GitHub. Your content stays in your repository. Rigel is open source under Apache-2.0.

[Website](https://rigelcms.dev) · [Documentation](https://rigelcms.dev/docs/)

## Projects

| Project | Description |
| --- | --- |
| [Rigel CMS](https://github.com/rigel-cms/rigel) | The editor and Astro integration. |

| [GitHub auth template](https://github.com/rigel-cms/rigel-github-auth-template) | Host your own authenticator on Cloudflare, Netlify or Vercel. |
